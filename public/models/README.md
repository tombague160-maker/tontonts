# Modèles 3D

Le site n’utilise plus de t-shirt 3D par défaut.

La personnalisation textile actuelle repose sur un mockup photo réaliste :

- `public/images/customizer/tshirt-front-realistic.webp`
- `public/images/customizer/tshirt-back-realistic.webp`

Si un jour un configurateur 3D industriel est ajouté, placer les modèles GLB/GLTF dans ce dossier et créer un nouveau composant dédié sans remplacer l’aperçu photo actuel.
